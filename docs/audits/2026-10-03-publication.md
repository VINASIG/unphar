## Source and integration

The project explicitly adopts the design system's Bright Playful Minimalism proposal. Local Space Grotesk, supplied logo/favicon bytes, Lucide Upload SVG, quiet CSS motion, dark mode, reduced motion and native accessible controls are integrated. Plain JavaScript receives strict JSDoc checking. A reviewed `web-static` SI-agent snapshot installs 37 managed payloads and seven local skills. Its instruction block is checked unchanged; the formatter ignores that immutable block's root file.

Pinned runtime packages are JSZip 3.10.2 and pako 3.0.2. Direct dependency choices and the TypeScript 6.0.3 compatibility decision are in `docs/TOOLCHAIN.md`. The current site loads no legacy root bundles or reference PHAR package. Their original files/notices are retained in source. Only 22 allowlisted publication files are copied into `dist/`, with HTML validation, asset digests, matching installed/vendor versions and source/output equality checks.

Font verification found 968 preserved glyphs, unchanged cmap, names, fvar/gvar and layout tables, and a 300-700 weight axis. The WOFF2 container is 48,952 bytes, compared with 134,112 bytes for the preserved TTF. The OFL notice remains.
