# Contribute to VINASIG Unphar

Read `AGENTS.md` and the linked project guides. Keep changes scoped to the existing browser-only converter, preserve user work and retain external notices. Use clear English technical copy and concise English imperative commit subjects.

Install the pinned Node/npm toolchain and run the commands in `README.md`. New archive behavior needs successful round trips and malformed-input cases. Reproduce reported UI problems in a real browser, keep before/after screenshots, fix source constraints and check keyboard/touch, enlarged text, light/dark and reduced motion.

Do not weaken a gate, remove an assertion, raise a budget or approve a broken screenshot to make a change pass. Record an actual blocker as NOT_RUN. Open issue reports with a minimal synthetic fixture or a non-sensitive screenshot; do not publish private archives or credentials. Use the private reporting channel for vulnerabilities.

The existing branch and shared Git history remain intact. Commit, push, pull requests and publication follow the current task's explicit authorization. Public contribution instructions create no new license grant; read `LICENSE_STATUS.md`.
